Đăng nhập — lấy JWT

Khớp đúng AuthController hiện tại: chỉ nhận username/password (hardcode test admin/admin), trả về field access_token. Token này có claim roles: ["ADMIN","REVIEWER"] và companyId: 1 sẵn.

Đúng quy trình bạn hay dùng ở Postman: gọi API sinh token (POST), copy chuỗi JWT trả về, dán vào ô dưới đây — console sẽ tự gắn Authorization: Bearer <token> cho mọi request tiếp theo, không khác gì chọn Bearer Token trong tab Authorization của Postman.

5Sửa field thủ công (audit trail)

PUT /api/v1/documents/{documentId} — extractedFields gửi dưới dạng chuỗi JSON đã escape. Sau khi gửi, kiểm tra bảng field_correction_audits trong DB.

Chỉ 3 status này được phép qua API cập nhật chung. APPROVED bị chặn cứng ở đây (trả lỗi 400) — phải dùng đúng Bước 6 (POST /approve).

7Xuất báo cáo Excel

Nạp lại cấu hình Template

POST /api/v1/templates/reload — Gọi API này để xóa cache và tải lại danh sách template (bao gồm Regex bóc tách) từ Database vào bộ nhớ ứng dụng.

Sử dụng sau khi bạn cập nhật bảng template_config hoặc template_field_config trong CSDL.
