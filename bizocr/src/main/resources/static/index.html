Hệ thống trích xuất và duyệt chứng từ OCR thông minh — Đăng nhập / Đăng ký để bắt đầu.

API sẽ kiểm tra tài khoản & mật khẩu qua PasswordEncoder trong CSDL và trả về JWT Bearer Token chứa roles và companyId.

Hệ thống sẽ tự động liên kết hoặc khởi tạo doanh nghiệp (Tenant Company) và gán quyền REVIEWER.

1Upload chứng từ & Tiếp nhận xử lý ngầm

POST /api/v1/documents/upload — Tải ảnh hóa đơn/chứng từ lên hệ thống. Server sẽ lưu trữ, sinh ID, và đẩy vào hàng đợi Redis (Redis Queue) để pipeline AI/OCR xử lý ngầm.

GET /api/v1/documents/{documentId}/file — Trả về file chứng từ gốc được lưu trữ trong hệ thống lưu trữ (StorageService).

4Phân loại loại văn bản nhanh

POST /api/v1/documents/classify — Thử nghiệm độc lập logic phân loại (Template Matcher / Regex / Keyword / Fallback AI) dựa trên văn bản OCR thô.

5Sửa trường dữ liệu & Ghi nhận Audit

PUT /api/v1/documents/{documentId} — Cho phép kiểm toán viên/reviewer hiệu chỉnh các trường đã bóc tách. Mọi thay đổi sẽ tự động ghi vết vào bảng field_correction_audit.

Chưa có dữ liệu. Bấm "Tải dữ liệu trường" phía trên.

Lưu ý: Trạng thái APPROVED bị chặn ở endpoint này để đảm bảo toàn vẹn quy trình duyệt (hãy dùng Bước 6 để Duyệt chính thức).
